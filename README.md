# 问道长生 · Godot 4 水墨挂机修仙

竖屏水墨风放置修仙小游戏：挂机修炼 → 突破 → 渡劫 → 飞升 → 转世。玩法参考《一念逍遥》这类挂机修仙；名称、文案、美术、音乐全部原创或程序生成。

**在线试玩（手机浏览器可玩）：** https://liush2yuxjtu.github.io/wendao-changsheng/


## 玩法
| 系统 | 说明 |
|---|---|
| 修炼 | 自动涨修为和灵石；「吐纳」点一下得 1 秒修为；可自动突破小境界 |
| 境界 | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，每境 初/中/后/圆满 |
| 突破 | 大境界有成功率，失败修为 -30%；破境丹每枚 +15%（最多 3 枚） |
| 寿元 | 每个大境界有寿元上限（100→5500 年），现实 12 秒 = 1 年。寿元耗尽则坐化，被迫转世（永久 +10%）。离线闭关不折寿。延寿丹可续命 |
| 功法 | 花灵石参悟，每重修炼 +30% |
| 炼丹 | 聚气丹（立得 60 秒修为）、破境丹、延寿丹 |
| 历练 | 一念逍遥式回合制战斗：攻击/防御/气血/速度 + 暴击·连击·反击·闪避·击晕·吸血六维属性及对应抗性（生效 = 己方属性 − 对方抗性），速度快者先手，20 回合未分胜负挑战方判负。9 张地图 + 妖王（妖王会放神通）；手动战斗进入俯视斗法台回放：圆形头像棋子（气血环、普通/精英/妖王框）、8 门神通各有特效、眩晕/灼烧/护盾状态、神通槽冷却，可倍速或跳过；自动历练只记日志 |
| 神通 | 8 门，按境界解锁、灵石习得、神通残卷升级（最高 10 层）；装备 1/2/3 门（练气/筑基/金丹起），按冷却自动释放：御剑术、回春诀、金刚护体、掌心雷、烈焰焚天、吸星大法、万剑归宗、九天神雷 |
| 镇妖塔 | 逐层挑战，首通得灵石；每 5 层镇塔妖王给神通残卷×2，每 10 层给破境丹 |
| 法宝 | 兵器（攻击）/ 护甲（气血、防御）/ 饰品（修炼速度），凡/灵/宝/仙四品，附 1–4 条随机战斗词条；更好的自动装备，差的分解成灵石；可强化 |
| 宗门 | 筑基后三选一：青云剑宗（攻伐）、丹鼎宗（丹道）、玄天道宗（修炼+寿元）。宗门任务攒贡献，职位越高修炼越快，贡献可兑换破境丹、灵草 |
| 奇遇 | 随机事件，部分需要抉择（古修洞府、神秘老者、受伤白狐） |
| 转世 | 飞升后转世永久 +50%；坐化转世 +10% |
| 离线 | 最多结算 8 小时 |

节奏（`tools/sim_balance.gd` 模拟）：全勤操作约 2 小时首次飞升；佛系挂机约 5–9 小时（有随机性；`tools/verify.sh` 会检查是否在合理区间）。

## 本地运行
1. 安装 Godot **4.3+**（标准版）。
2. 项目管理器 → 导入 → 选 `project.godot` → F5。

## 目录
| 路径 | 内容 |
|---|---|
| `scripts/game_data.gd` | 全部数值与文案（调平衡只改这里） |
| `scripts/game_state.gd` | 游戏逻辑与存档（Autoload `GameState`） |
| `scripts/combat.gd` | 回合制战斗引擎（纯函数，输出逐条事件供界面回放） |
| `scripts/battle_arena.gd` | 俯视斗法台：棋子、状态与神通特效的程序绘制 |
| `scripts/ink_draw.gd` | 绘图工具：SVG 路径解析、头像、神通图标（坐标照搬设计稿） |
| `scripts/main.gd` | UI（纯代码搭建）、主题、特效 |
| `scripts/ink_background.gd` | 程序绘制的水墨山水背景 |
| `scripts/audio_manager.gd` | 生成式古琴背景乐 + 音效 |
| `assets/audio/` | 由 `tools/make_audio.py` 合成的音频 |
| `assets/fonts/` | 裁剪后的 Noto Serif SC（OFL 授权，见 `NOTO-LICENSE.txt`） |
| `tools/` | 验证与发布（`verify.sh`）、字体覆盖检查、手机冒烟测试、数值模拟、音频合成、字体裁剪 |
| `.claude/skills/verify/` | `/verify` 技能：让 agent 按同一流程验证与发布 |

**改了中文文案后**要重新裁剪字体，否则新字在网页/手机上会显示成方块：
```bash
python3 tools/make_font.py      # 需要 fonttools 和 Noto Serif CJK
```

## 验证与部署（没有 CI，全部在本地做）
```bash
bash tools/verify.sh            # 资源/字体覆盖 → 无界面运行 → 数值模拟 → 网页导出 → 手机冒烟
bash tools/verify.sh --fast     # 前三项，几秒钟（pre-push 钩子跑的就是它）
bash tools/verify.sh --deploy   # 全部通过后发布到 GitHub Pages（gh-pages 分支），并验证线上版
git config core.hooksPath .githooks   # 一次性：每次 push 前自动跑 --fast
```
用 Claude Code 的话直接 `/verify`。细节和环境要求见 `.claude/skills/verify/SKILL.md`。
