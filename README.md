# 问道长生 · Godot 4 水墨挂机修仙

竖屏水墨风放置修仙小游戏：挂机修炼 → 突破 → 渡劫 → 飞升 → 转世。玩法参考《一念逍遥》这类挂机修仙；名称、文案、美术、音乐全部原创或程序生成。

**在线试玩（手机浏览器可玩）：** https://liush2yuxjtu.github.io/wendao-changsheng/


## 玩法
| 系统 | 说明 |
|---|---|
| 修炼 | 自动涨修为和灵石；「吐纳」点一下得 1 秒修为；可自动突破小境界 |
| 境界 | 练气→筑基→金丹→元婴→化神→炼虚→合体→大乘→渡劫，每境 初/中/后/圆满 |
| 突破 | 大境界有成功率，失败修为 -30%；破境丹每枚 +15%（最多 3 枚） |
| 寿元 | 每个大境界有寿元上限（100→5500 年），现实 12 秒 = 1 年。寿元耗尽则坐化，被迫转世（永久 +10%）。离线闭关不折寿。延寿丹可续命 |
| 功法 | 花灵石参悟，每重修炼 +30% |
| 炼丹 | 聚气丹（立得 60 秒修为）、破境丹、延寿丹 |
| 历练 | 自动回合制战斗，9 张地图 + 妖王；可自动历练 |
| 法宝 | 兵器（攻击）/ 护甲（气血）/ 饰品（修炼速度），凡/灵/宝/仙四品；更好的自动装备，差的分解成灵石；可强化 |
| 宗门 | 筑基后三选一：青云剑宗（攻伐）、丹鼎宗（丹道）、玄天道宗（修炼+寿元）。宗门任务攒贡献，职位越高修炼越快，贡献可兑换破境丹、灵草 |
| 奇遇 | 随机事件，部分需要抉择（古修洞府、神秘老者、受伤白狐） |
| 转世 | 飞升后转世永久 +50%；坐化转世 +10% |
| 离线 | 最多结算 8 小时 |

节奏（`tools/sim_balance.gd` 模拟）：全勤操作约 2 小时首次飞升；佛系挂机约 6–9 小时。

## 本地运行
1. 安装 Godot **4.3+**（标准版）。
2. 项目管理器 → 导入 → 选 `project.godot` → F5。

## 目录
| 路径 | 内容 |
|---|---|
| `scripts/game_data.gd` | 全部数值与文案（调平衡只改这里） |
| `scripts/game_state.gd` | 游戏逻辑与存档（Autoload `GameState`） |
| `scripts/main.gd` | UI（纯代码搭建）、主题、特效 |
| `scripts/ink_background.gd` | 程序绘制的水墨山水背景 |
| `scripts/audio_manager.gd` | 生成式古琴背景乐 + 音效 |
| `assets/audio/` | 由 `tools/make_audio.py` 合成的音频（首次 CI 运行时自动生成并提交） |
| `assets/fonts/` | 裁剪后的 Noto Serif SC（OFL 授权，见 `NOTO-LICENSE.txt`） |
| `tools/` | 数值模拟、音频合成、字体裁剪脚本 |

**改了中文文案后**要重新裁剪字体，否则新字在网页/手机上会显示成方块：
```bash
python3 tools/make_font.py      # 需要 fonttools 和 Noto Serif CJK
```

## 部署
推送到 `main` 后，GitHub Actions 会自动导出网页版（单线程版本，不需要跨域隔离响应头）并发布到 GitHub Pages。
